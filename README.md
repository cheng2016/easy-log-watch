# Easy Log Watch

本地一键解密、预览、搜索 Mars / 微信风格 **`.xlog`** 日志。

不用敲命令行、不用每次找官方 Python 脚本、不用把整份明文导出来再翻——双击启动，浏览器里就能搞定从解密到排障的全流程。

---

## 为什么用它？

排查线上问题，日志经常是一堆 `.xlog` 或压缩包：

- 官方脚本要自己装依赖、改路径、一条条跑
- 加密日志还要换脚本、改私钥
- 解出来的明文动辄几十 MB，用记事本打开又慢又卡
- 多天、多设备日志散落各处，过两天就忘了哪份对应哪次问题

**Easy Log Watch** 把这些步骤收成一个本地小工具：

| 痛点 | 这里怎么解决 |
|------|----------------|
| 命令行解密麻烦 | 拖拽 / 选文件 / 选文件夹，点一下开始解密 |
| 加密 / 未加密脚本不同 | 下拉选择 `scripts/` 里的解密脚本 |
| 明文太大不好翻 | 开头 / 末尾分段预览，按需滚动加载 |
| 找关键字费劲 | 支持包含、任一、全部、正则，还能按级别过滤 |
| 历史对不上号 | 自动留档，可重命名、写备注，按日期分组 |
| 已有明文还要再解一遍 | 右侧预览区可直接拖入 `.log` / 粘贴文本 |

数据都在你本机，不上传云端。

## 功能一览

### 解密

- 支持单个 / 多个 **`.xlog`**，以及 **`.zip`**（自动抽出其中的 xlog）
- 支持 **整文件夹** 上传（保留相对路径，方便按天、按设备整理）
- **可切换解密脚本**：默认 Mars 未加密脚本；加密或其他格式把对应 `.py` 丢进 `scripts/` 即可
- 解密进度实时显示；多文件结果可打包下载

### 预览与搜索

- 打开解密后的 `.xlog.log`，快速看 **开头 / 末尾**
- **直接拖入已解密文件**：把 `.log` / `.txt` / `.xlog.log` 等拖到右侧预览区，或在预览区粘贴文本，即可预览与搜索（无需再走解密）
- 大文件分段加载，滚动继续往下（或往上）看，不必一次塞进内存
- **关键词搜索**：普通包含、`a\|b` 任一、`a&b` 全部、正则
- **级别过滤**：E / W / I / D / V
- 点搜索结果可跳到附近上下文
- 搜索历史本机记住，方便反复查同一类问题

### 历史管理

- 每次解密自动记一条历史
- 按日期分组（今天 / 昨天 / 具体日期）
- 可改标题、写备注，方便以后辨认
- 可删除整条记录及本地文件

## 30 秒上手

### 环境

- Windows（自带 `start.bat`）
- Python 3，并已加入 `PATH`

### 启动

1. 双击项目根目录的 **`start.bat`**
2. 自动检查 / 安装依赖，启动本地服务
3. 浏览器打开 [http://127.0.0.1:5000/](http://127.0.0.1:5000/)

已经在跑的话，再点一次 `start.bat` 只会打开浏览器，不会起第二个服务。

### 第一次解密

1. 把 `.xlog` / `.zip` 拖进上传区，或点选文件 / **选文件夹**
2. 「解密脚本」一般保持默认即可（未加密 xlog）
3. 点 **开始解密**
4. 左侧历史里点开任务 → 点 **解密文件 `.xlog.log`** 预览或搜索

## 如何更换解密脚本？

所有解密脚本统一放在：

```text
scripts/
```

**不要**把脚本乱放在项目根目录或其他文件夹。

### 步骤

1. 把要用的 `.py`（例如官方 `decode_mars_crypt_log_file.py`）复制进 `scripts/`
2. 若是加密脚本，按脚本说明改好里面的 **`PRIV_KEY`**
3. **刷新浏览器页面**
4. 在「解密脚本」下拉里选中它，再解密

### 脚本约定（兼容官方 Mars 风格）

工具会这样调用你选中的脚本：

```text
python <脚本.py> <某个.xlog>
```

成功后应在同目录生成：

```text
<某个.xlog>.log
```

### 可选说明文案

脚本开头加一行，界面里会显示简介，方便区分：

```python
# DESCRIPTION: Mars 加密 xlog：ECDH + TEA（PRIV_KEY 写在脚本内）
```

默认自带：

| 脚本 | 用途 |
|------|------|
| `decode_mars_nocrypt_log_file.py` | Mars **未加密** xlog，只做 zlib / zstd 解压 |

## 搜索小技巧

| 写法 | 含义 |
|------|------|
| `timeout` | 普通包含（不区分大小写） |
| `timeout\|crash` 或 `timeout OR crash` | 命中任一 |
| `login&fail` 或 `login AND fail` | 必须同时包含 |
| 打开「正则」 | 按正则匹配 |
| 点级别 E/W/I… | 只看对应级别行 |

搜到结果后，点击某一行可跳到该行附近上下文，继续上下滚动浏览。

## 目录结构

```text
easy-log-watch/
├── README.md                 ← 你正在看的说明
├── start.bat                 ← 一键启动
├── app.py                    ← Web 服务
├── script_runner.py          ← 调用 scripts/ 里的解密脚本
├── wait_ready.py             ← 启动就绪检测
├── requirements.txt
├── scripts/                  ← 只放解密用 .py
│   └── decode_mars_nocrypt_log_file.py
├── templates/
│   └── index.html            ← 界面
├── .uploads/                 ← 运行时数据（历史与解密结果，可删）
└── .runtime/                 ← 启动缓存（依赖检查标记等，可删）
```

`.uploads/`、`.runtime/` 都是本地临时/缓存目录（点开头方便辨认）。关掉服务后可以随时整夹删除；下次启动会自动重建。

## 使用建议

- **未加密日志**：默认脚本即可
- **加密日志**：放入官方 crypt 脚本，改好 `PRIV_KEY`，下拉切换后再解
- **一次拖一整周的文件夹**：比逐个文件快，历史标题也能看出目录名
- **先搜再翻上下文**：比从头打开整份 log 高效得多
- 重要现场：解密后在历史里写一句备注（版本号、用户、复现步骤）

## 常见问题

**Q：页面打不开？**  
再跑一次 `start.bat`。若仍失败，看最小化的 `easy-log-watch` 黑窗口里的报错；确认 Python 在 PATH 中。

**Q：解密失败 / 没有明文？**  
多半是脚本和日志类型不匹配（用了未加密脚本去解加密日志）。换对脚本后再试。

**Q：换了脚本下拉里没有？**  
确认文件在 `scripts/` 且后缀是 `.py`，然后 **刷新页面**。

**Q：能部署到服务器给同事用吗？**  
当前按本机工具设计（含本机记住的搜索词、私钥在脚本文件里等）。若要多人共用，请自行评估安全与隔离，默认推荐本机使用。
